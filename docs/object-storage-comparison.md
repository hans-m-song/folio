# Self-hosted S3 storage comparison

This dated research record preserves decision evidence. Recheck external product
capabilities and prices before a new decision; provider acceptance requires the
verification gates recorded below.

Research snapshot: 2026-10-15. This compares SeaweedFS, Garage, Ceph RGW, RustFS, and Versity Gateway as MinIO alternatives; LocalStack is out of scope.

Folio's storage flow depends on presigned GET/PUT, browser CORS, atomic create-only `If-None-Match: *` PUT, SHA-256 checksum verification returned by `HEAD` with checksum mode enabled, object metadata, and exact-key deletion ([storage implementation](../src/documents/storage.ts)). “S3-compatible” means an implementation-specific subset: each candidate must pass those exact requests before it is treated as interchangeable.

| **Ceph RGW**        | The [official feature table](https://docs.ceph.com/en/latest/radosgw/s3/) covers a broad S3 surface, including `PutObject`, `HeadObject`, CORS-related operations, and multipart uploads. It does not establish Folio's conditional-create and checksum-on-HEAD sequence; validate those against the deployed Ceph release.                                                                                                                                                                                                                                                                                                                                        | Ceph has a [multi-license repository](https://github.com/ceph/ceph) including [LGPL-2.1 materials](https://github.com/ceph/ceph/blob/main/COPYING-LGPL2.1); review the actual components and packages used. Highest operational burden when introduced only for Folio: production guidance describes Monitor, Manager, and OSD daemons, with RGW added for object access ([cluster components](https://docs.ceph.com/en/latest/start/ceph-cluster-components/)). Sensible mainly if a Ceph cluster already exists. |
| **RustFS**          | RustFS publishes a [commit-pinned compatibility matrix](https://docs.rustfs.com/en/reference/s3-compatibility): selected presigned URL, CORS, metadata, and object cases are tested; other standard cases remain planned or excluded. That matrix does not demonstrate Folio's create-only PUT plus SHA-256 `HEAD` contract. Its [CORS guide](https://docs.rustfs.com/en/administration/cors) documents explicit browser-origin configuration.                                                                                                                                                                                                                     | [Apache-2.0](https://github.com/rustfs/rustfs). RustFS announced 1.0 GA on 2026-09-16 ([vendor announcement](https://rustfs.com/blog/announcing-rustfs-1-0-0-ga/)); treat the short post-GA history as a reason for a controlled pilot, not as proof of instability.                                                                                                                                                                                                                                               |
| **Versity Gateway** | A gateway over POSIX filesystems, ScoutFS, Azure Blob, or another S3 service, rather than a replicated object-storage engine ([project README](https://github.com/versity/versitygw)). Its [POSIX backend guide](https://github.com/versity/versitygw/wiki/POSIX-Backend) documents per-key serialization for conditional `PutObject` publication and configurable lock modes. Verify the selected filesystem's locking, browser CORS/presigned flow, and SHA-256-on-HEAD behavior.                                                                                                                                                                                | [Apache-2.0](https://github.com/versity/versitygw). Potentially lowest added storage cost when Folio already has a suitable POSIX filesystem; durability, replication, and lock semantics then depend on that filesystem.                                                                                                                                                                                                                                                                                          |

The project sources provide uneven evidence, not a defensible market-share ranking. Garage says it has used its own software in production since 2020 ([repository](https://github.com/deuxfleurs-org/garage)); RustFS's deployment and star counts are vendor-reported in its GA announcement. Such claims and repository activity are not independently audited adoption or comparable reliability measurements. Compatibility matrices are also scoped differently: RustFS pins a test snapshot, while Garage warns its table may be outdated. No source reviewed provides a comparable, independently measured total cost of ownership.

**Practical order:** pilot SeaweedFS first; consider Versity when using an existing filesystem; use Ceph RGW when operating Ceph already; assess RustFS after its Folio-specific contract passes; exclude Garage unless a selected release proves atomic create-only PUT support. Changing Folio's safety contract is a separate design decision. For every viable candidate, test concurrent requests to the same key (one create succeeds), presigned GET/PUT with the actual browser headers and CORS origin, SHA-256 verification through `HEAD` with checksum mode enabled, metadata round-trip, and exact-key deletion. No candidate is certified by this desktop research alone.
